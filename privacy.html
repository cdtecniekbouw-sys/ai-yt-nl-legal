Privacy Policy

Last updated: 22 November 2026

This Privacy Policy explains how the AI Nieuws NL application ("the Application", "we", "us") handles information when it connects to Google services. The Application is a private content-automation tool operated by its owner to publish videos to the owner's own YouTube channel. It is not offered as a public service to third-party users.

1. Information we access

The Application uses Google OAuth 2.0 to access the YouTube Data API v3 with the scope https://www.googleapis.com/auth/youtube. This access is limited to the channel owner's own Google account. Through this scope the Application may:

  • Upload videos created by the Application to the owner's YouTube channel;
  • Set video metadata (title, description, tags, thumbnail, language);
  • Read the status of videos uploaded by the Application.

We do not access Gmail, Google Drive, Google Calendar, Contacts, or any other Google product, and we do not request any scope beyond the one listed above.

2. How we use the information

Information obtained through the YouTube Data API is used solely to upload and manage the videos produced by the Application on the owner's own channel. It is not used for advertising, profiling, analytics, or any purpose unrelated to this function.

3. Storage and security

OAuth credentials (including the refresh token) are stored locally on the owner's own computer in a protected secrets/ folder and are never transmitted to or stored on any third-party server controlled by us. No user data is shared with advertisers, data brokers, or any other third party.

4. Data retention and deletion

Because the Application only operates on the owner's own account and stores credentials locally, no third-party personal data is retained. The owner can revoke the Application's access at any time at myaccount.google.com/permissions, which immediately invalidates the stored credentials.

5. Google API Services User Data Policy

AI Nieuws NL's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

In particular, we do not use or transfer Google user data for serving advertisements, and we do not allow humans to read this data, except as necessary for security purposes, to comply with applicable law, or with the owner's explicit consent.

6. Children's privacy

The Application is a private tool and is not directed at children. It does not knowingly collect information from children.

7. Changes to this policy

We may update this Privacy Policy from time to time. Material changes will be reflected by updating the "Last updated" date at the top of this page.

8. Contact

Questions about this Privacy Policy can be sent to cdtecniekbouw.bouw@gmail.com.
