AI Nieuws NL

Dutch-language YouTube channel about artificial intelligence and AI tools.

What this application does

AI Nieuws NL is a content automation project that produces and publishes short Dutch-language videos about artificial intelligence and AI tools. The project runs a local pipeline that writes a script, generates a voice-over, renders the video, and then uploads the finished video to the project's own YouTube channel.

The application connects to the YouTube Data API v3 using Google OAuth 2.0. The only Google account it acts on is the channel owner's own account. It uses a single OAuth scope, https://www.googleapis.com/auth/youtube, strictly to:

  • Upload videos that the project itself has produced;
  • Set the video's title, description, tags, language and thumbnail;
  • Read back the upload status of those same videos.

The application does not access, collect, or process any other data from the user's Google account, and it does not serve any third-party users.

Google user data

AI Nieuws NL's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
